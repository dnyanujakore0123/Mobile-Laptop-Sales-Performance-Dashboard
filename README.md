# Mobile-Laptop-Sales-Performance-Dashboard
This project analyzes mobile and laptop sales data to track revenue, quantity sold, and customer trends. The dashboard provides insights into monthly sales performance, regional distribution, and product-wise analysis.

🔹 Tools Used

Power BI

Power Query

DAX

🔹 Key Insights

Total Orders: 50K

Average Price: 103K

Sales are consistent across months with slight peaks

Laptops and Mobile Phones contribute equally to revenue

Sales distribution is balanced across all regions

🔹 Features

Monthly Sales Trend Analysis

Product-wise Revenue & Quantity

Region-wise Sales Distribution

Brand-wise Price Comparison

Interactive Filters (Region, Brand, Product)
